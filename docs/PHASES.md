# KeyOverlay Phases

1. **Repo setup**: workspace, tooling, CI, and scaffolding.
2. **Input hooks**: global keyboard/mouse capture for Windows.
3. **Overlay**: transparent overlay window and rendering pipeline.
4. **Hotkeys + tray**: tray menu, toggles, and global shortcuts.
5. **Settings + persistence**: configuration UI and storage.
6. **Polish + release**: packaging, crash reporting, and documentation.
